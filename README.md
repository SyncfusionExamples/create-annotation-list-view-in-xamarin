# create-annotation-list-view-in-xamarin

This example demonstrates how to create an annotation list view and navigate to annotations by selection using the Syncfusion® PDF Viewer. The sample shows how annotations available in a PDF document can be listed and how selecting an annotation from the list navigates the PDF Viewer to the corresponding location.

## Description

This example focuses on enhancing PDF navigation by presenting annotations in a list view. All annotations present in the loaded PDF document are collected and displayed to the user. When an annotation is selected from the list, the PDF Viewer automatically navigates to that annotation.

This approach helps users efficiently review, manage, and navigate annotated PDF documents.

## Supported Platforms

This example supports the following platforms:

- Android  
- iOS  
- UWP (Universal Windows Platform)

The annotation listing and navigation behavior is consistent across all supported platforms.

## Prerequisites

Before running this example, ensure you have the following:

- Visual Studio with Xamarin support  
- A Xamarin.Forms application  
- Syncfusion® PDF Viewer for Xamarin configured in the project  

## How It Works

The example follows these steps:

- A PDF document is loaded into the Syncfusion PDF Viewer  
- Annotations present in the document are retrieved programmatically  
- The retrieved annotations are displayed in a list view  
- Selecting an annotation navigates the viewer to the corresponding location in the PDF  

## Use Cases

This example is useful for scenarios such as:

- Reviewing documents containing multiple annotations  
- Quickly navigating to comments, highlights, or shapes  
- Improving user experience in document review applications  

## Conclusion

This sample provides a practical way to improve annotation visibility and navigation in Xamarin applications. By combining an annotation list view with the Syncfusion® PDF Viewer, users can easily access and navigate annotated content, resulting in a smoother and more efficient document review experience.

For more details, refer to the official Syncfusion [documentation](https://help.syncfusion.com/document-processing/pdf/pdf-viewer/xamarin/overview) and [API reference](https://help.syncfusion.com/cr/xamarin/Syncfusion.SfPdfViewer.XForms.html).
